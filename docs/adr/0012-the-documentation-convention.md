# The documentation convention

`AGENTS.md` stays a short entry point — the purpose, the toolchain commands, the invariants and
pointers — and the specifications live in `docs/SPECS.md` and `docs/features/`, one file per feature.
`GLOSSARY.md` and `docs/adr/` are the vocabulary and the decision log every engineering skill reads,
and `docs/agents/` holds how those skills consume them.

The repository's convention is `AGENTS.md`, `docs/SPECS.md` and `docs/features/`. `docs/architecture.md`,
`docs/conventions.md` and `CLAUDE.md` are deliberately not used: a second place to look is a second
place to go stale.
